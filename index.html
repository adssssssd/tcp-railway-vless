🧭 How to run it (which port)

1. Deploy — push this repo to Railway (Dockerfile builds Xray).
2. Expose a TCP proxy — Railway → service → Networking → TCP Proxy:
  • Public port: whatever (e.g. 17505) → Internal port: 5432
3. That's it — xray listens on the internal port, the TCP proxy maps it.
Must run on the internal port set below — the same port the Railway TCP proxy forwards to. Override with env PORT (default 5432).
